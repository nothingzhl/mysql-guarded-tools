# 0.8.0-rc.1 环境变量密码审查

本次变更从已发布的 0.7.0-rc.1 分支开发。旧版钥匙串实现与审查可在旧 tag 查看；本版改为环境变量，不再把旧版真实钥匙串结果当作本版验收证据。

## 变更

- 删除 Keychain helper、Swift 编译与原生密码弹框，不导出或删除旧条目。
- 配置只保存 passwordSource 与 passwordKey；MCP / 页面字段为 password_source 与 password_key。
- MYSQL_PASSWORD 为共用来源；MYSQL_PASSWORDS_JSON 为按名称引用的 JSON。JSON 缺少项不回退共用密码。
- 缺少环境值时仍可配置引用，但连接在发起网络请求前拒绝；某个连接未配置不影响其他已配置连接。
- 删除连接不修改外部环境，配置保存失败也不会改变密码来源值。
- 窗口调整为来源选择与逻辑名称，不接收密码值。
- .mcp.json 显式声明向子进程传递两个来源变量。桌面宿主进程是否实际继承，仍需要用户环境验收。
- 锁、原子配置替换、SQL 只读与 UPDATE 审查边界继续保留。

## 验证范围

本地 52 项自动化测试通过，npm audit 报告 0 已知漏洞，发布校验与 UI JavaScript 语法检查通过。

自动化测试覆盖环境缺失、空值、格式错误、JSON 不回退、引用切换、旧配置、配置保存失败、删除、锁及完整 MCP 调用链。测试使用临时配置、虚构密码及回环不可用端口，不读取或修改真实密码。

发布校验检查市场路径、版本、启动器、变量声明、无原生密码组件，以及个人路径和敏感内容的启发式扫描。

## 限制

环境变量不是加密存储，进程环境可被本机有权限的工具读取。用户需自行在宿主环境设置变量并完全重启 Codex。未自动更新系统环境，也未对业务连接执行密码迁移。

真实 MySQL 验收、浏览器交互、桌面变量继承和 Windows 实机运行尚未完成。55 项旧版测试数字不适用于本版；最终测试结果以本次运行记录为准。
