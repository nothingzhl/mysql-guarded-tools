# MySQL 插件安全与发布准备

目标：将当前 0.6.0 整理为可共享 Git 市场中的 0.7.0 候选版本，不发布远端、不替换当前运行版本。

- 检查新增/编辑、窗口鉴权、钥匙串命令和保存失败路径。
- 改用 Security.framework helper，以 stdin 传递密码；密码输入仅通过 macOS 隐藏弹框。
- 保存加跨进程锁和版本检查；普通异常回滚钥匙串，使用独占临时文件原子替换配置，明确崩溃边界。
- 收紧窗口参数白名单，修复刷新令牌丢失，区分已保存与运行时刷新失败。
- 创建相对路径市场清单、安装/升级说明、CI、依赖锁文件、发布校验与源码归档。
- 隔离测试与依赖审计通过后初始化本地 Git 仓库；不触碰用户实际连接或钥匙串。
